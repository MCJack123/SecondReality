# Second Reality for ComputerCraft
A port of [Future Crew's Second Reality demo](https://github.com/mtuomi/SecondReality) to ComputerCraft.

## Command-line arguments
The first argument may be a part to jump to - this is a file name in this repo. If a second argument is present and run on CraftOS-PC, the experimental graphics mode will be selected. Be aware some effects are broken in graphics mode due to using text tricks.
